# Artifact content storage implementation report

Implemented operations are registered and dispatched through Core: `artifact.session.bind`, `artifact.store.begin`, `artifact.store.append`, `artifact.store.commit`, `artifact.metadata`, `artifact.content.read`, `artifact.content.list`, and `artifact.session.output`.

The task-session spool preserves native bytes in immutable, UTC date and ID sharded payload files. Uploads use ordered base64 transport chunks capped at 64 MiB, verify per-chunk and full SHA-256 hashes, publish complete version directories by rename, hash manifests, and keep incomplete uploads out of lists and reads. Session bindings, upload state, catalog/chunk rows, idempotency results, and content audit events use the existing SQLite authority. List and output are bounded by page size; raw reads return one bounded chunk with a continuation cursor.

Model-facing MCP tools remain metadata-only. Raw payload retrieval is host/operator-only and requires a transport-verified principal with a bound Engagement and session. Taric does not redact, scan, decrypt, execute, manage credentials, or apply retention policy to opaque payload bytes.

The implementation now includes durable publication markers, startup publication recovery, SQLite keyset catalog pagination with bound cursors and watermarks, bounded execution output cursors, atomic catalog/chunk association, sidecar path containment, stale Attempt fencing, and incremental file reconciliation exposed through `audit.doctor` and `audit.reconcile`. Manifest segment rollover remains intentionally bounded to the current root manifest contract; a future change may add physical segment rollover without changing the opaque reference API. The 100 GiB verification uses a synthetic metadata fixture and does not materialize 100 GiB in one process response. The focused Artifact tests cover binary round trip, external references, transport hashing, duplicate ordinals, idempotency conflicts, stale fencing, restart catalog reload, symlink escape, tampering, missing files, execution metadata, CLI/adapter authorization, projection/snapshot poisoning, indexed pagination, and bounded scale output.
